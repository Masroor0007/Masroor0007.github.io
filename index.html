Selected work

Published2026

CG-ECG: a selective classification abstention framework for trustworthy ECG classification

Medical Imaging and Computer-Aided Diagnosis (MICAD) 2026, Edinburgh

Before an ECG prediction reaches a clinician, it has to pass two gates: the model must be confident, and the case must fall inside the region of embedding space where that class lives. If either gate fails, the prediction is held back for a human to read.

DefendedApril 2026

Deep learning abstention using geometric algorithms

MS thesis, University of Texas at Tyler. Committee chair: Dr. Yi Li.

Each class gets a convex hull in a compressed embedding space, checked with linear programming so no two classes overlap. A prediction is kept only when it lands inside the hull of the class it predicts. I tested it on 1D ECG signals, ECG images and chest X-rays, reaching 99.71% accuracy on the chest X-rays it kept.

Heartbeat ECGs, MIT-BIH test set: 84.3% of cases kept, and every kept prediction was correct. The other 15.7% went to a clinician.

Published2025

MagCount: automated counting of Southern Magnolias for nursery inventory

International Plant Propagators' Society (IPPS)

Drone imagery and a YOLOv8 detector count magnolia trees row by row with 95.2% accuracy, replacing manual inventory counts. Image tiling and iterative retraining got it there, and it also reports crown size and foliage cover for planning.

AgriEye: turning manual drones into autonomous ones

A compact add-on module for agricultural survey drones in Mississippi. It pairs an onboard object-detection model, exported to ONNX, with an ELRS radio receiver and INAV flight control, so a manually flown drone can fly and count on its own.
